# Твій хід - лабораторна №9

Адаптивна форма зворотного зв’язку та клієнтська валідація. Окрема копія основи лабораторної №8.

HTML, Tailwind CSS 3.4.17, Vanilla JavaScript. Серверного надсилання даних немає.

## Запуск

```sh
npm ci
npm test
npm run build:site
```

Відкрити папку у VS Code, запустити Live Server для `index.html`. Або віддати папку `dist` будь-яким HTTP-сервером. ES-модулі потребують HTTP: відкриття через `file://` не є коректним запуском.

## Код форми

- `index.html`, розділ `#contact`: п’ять обов’язкових полів, політика та кнопка; `#feedbackModal`: модальне повідомлення.
- `components/feedback-form.html`: окрема копія розмітки компонента для перегляду.
- `js/validation-rules.mjs`: чисті функції, повертають текст помилки або порожній рядок.
- `js/validation.js`: події input/change/blur/submit, UI-стани, фокус, відкриття й закриття dialog.
- `tests/validation.test.mjs`: 42 позитивні, негативні та граничні перевірки правил.
- `tailwind.config.cjs`, `css/input.css`: тема й генерація CSS; `css/custom-styles.css`: власні доповнення.
- `scripts/build.mjs`, `vercel.json`: збірка лише публічних файлів у dist для Vercel.

## Правила

Ім’я: 2–60 одиниць UTF-16 після trim та NFC, літери, апостроф, дефіс, одиночні пробіли між частинами. Email: навчальне ASCII-правило з доменною крапкою, без подвійної крапки в локальній частині; до 254 загалом і 64 до @. Телефон: строго `+380` і дев’ять цифр; пробіли не виправляються автоматично. Повідомлення: 10–1000 одиниць UTF-16 після trim. Згода: checked.

Це перевірка формату, а не існування пошти/номера. Повний RFC email, міжнародні IDN-адреси та підрахунок графем не реалізовані. Для справжнього надсилання потрібні API, серверна перевірка й окремі правила оброблення даних.

## Доступність і взаємодія

Label пов’язаний з id через for; підказки й статуси — aria-describedby. Помилка має текст і aria-invalid, а не лише червону рамку. Submit перевіряє всі поля та фокусує перше помилкове. Після успіху form.reset очищає введення. Native dialog.showModal робить фон inert; закривання кнопкою, Escape або зовнішнім кліком, повернення фокусу до submit. Форма не надсилає запитів і не зберігає контактів у localStorage. Без JS кнопка вимкнена.

Адаптивність: grid-cols-1, від md (768 CSS px) grid-cols-2 для імені/email; решта елементів md:col-span-2. Це CSS Grid. Префікс md — умова ширини, не Flexbox.
