# Лабораторна №9: пояснення для захисту

## Скажи на початку

«До нашого лендингу я додав адаптивну форму: ім’я, email, український телефон, повідомлення та згоду. JavaScript перевіряє формат на клієнті, показує помилки біля поля й не дозволяє перейти до успіху за наявності помилки. Після коректного заповнення форма очищається і відкривається модальне повідомлення. Реального надсилання на сервер у цій навчальній версії немає».

## 12 контрольних питань

1. **Label/for.** Дають полю доступну назву й дозволяють фокусувати його натисканням на напис. Placeholder зникає під час введення й не замінює label.
2. **type=tel.** Телефон — рядок із +, не число для обчислень. На мобільному браузер може показати телефонну клавіатуру. Тип tel сам не перевіряє український формат.
3. **Client/server.** Клієнтська перевірка покращує UX, але її можна обійти. Сервер повинен повторити перевірки перед зберіганням/надсиланням.
4. **^ і $.** Межі початку та кінця рядка. Без них regex може знайти правильний фрагмент усередині неправильного номера.
5. **Крапка.** Звичайна . у regex означає будь-який символ, крім деяких роздільників рядка; \. шукає буквальну крапку.
6. **Плюс.** Квантифікатор + означає «один або більше». Для буквального знака + телефону використано \+.
7. **preventDefault.** Скасовує стандартне надсилання/навігацію, дозволяє спочатку перевірити дані й показати локальний результат.
8. **Модальність.** У нашому коді native dialog.showModal + backdrop:bg-ink/60; фіксований div з великим z-index сам по собі не робить фон inert.
9. **Зовнішній клік.** Якщо target не dialog — не закриваємо; якщо це dialog — звіряємо координати з його прямокутником. Клік по білій картці всередині меж лишає її відкритою.
10. **Reset.** Очищає попереднє повідомлення й згоду після успіху. Візуальні помилки та службовий стан очищаються окремо.
11. **Імена й edge cases.** Лише A–Z відкине кирилицю; \w також не є універсальним правилом імен. Є апострофи, дефіси, комбіновані Unicode-символи. Наше правило навчальне, не універсальний стандарт усіх імен світу.
12. **ШІ.** Код може мати занадто слабкий regex, недоступну модалку, HTML-ін’єкцію або неправдиве «надіслано». Тому перевіряємо код і запускаємо негативні/граничні тести.

## Regex телефону по частинах

`/^\+380\d{9}$/`: `/.../` — літерал regex; `^` початок; `\+` буквальний плюс; `380` код; `\d{9}` рівно дев’ять цифр; `$` кінець. `+380501234567` підходить; `0501234567`, `+380 501234567`, зайва цифра — ні.

## Покажи викладачу

1. Порожня форма → submit → червоні тексти та фокус першого поля.

3. Виправити на +380501234567, повідомлення ≥10, checked → зелений стан.
4. Submit → модалка; пояснити, що це клієнтська демонстрація.
5. Закрити, показати очищення; у DevTools змінити ширину до 375 px → одна колонка.
